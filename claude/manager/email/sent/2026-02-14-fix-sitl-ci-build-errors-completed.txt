## Problem Identified

macOS and Windows CI builds were failing with:
```
error: unused function 'sitlCANInitSocketCAN' [-Werror,-Wunused-function]
error: unused function 'sitlCANReceiveSocketCAN' [-Werror,-Wunused-function]
error: unused function 'sitlCANTransmitSocketCAN' [-Werror,-Wunused-function]
error: unused function 'sitlCANGetStatsSocketCAN' [-Werror,-Wunused-function]
```

**Root Cause:** SocketCAN function declarations existed unconditionally but implementations were inside `#ifdef __linux__` blocks. On non-Linux platforms, this made them "unused" warnings, which became errors with `-Werror` compiler flag.

---

## Solution Applied

Fixed forward declarations in `src/main/drivers/dronecan/libcanard/canard_sitl_driver.c`:
- Guarded SocketCAN-specific declarations with `#ifdef __linux__`
- Left stub function declarations always visible
- Kept socket.h includes unguarded (macOS has POSIX socket support)

**Key Insight:** The original unguarded socket.h includes were correct. The problem was unused forward declarations on non-Linux platforms, not the includes themselves.
