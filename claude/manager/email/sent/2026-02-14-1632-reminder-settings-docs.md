# Reminder: Run docs update script when settings change

**Date:** 2026-02-14 16:32 | **From:** Manager | **To:** Developer | **Priority:** MEDIUM

---

When adding or modifying configuration settings in settings.yaml, always run the documentation update script afterward.

The script generates updated documentation for the settings. This ensures the INAV configurator and other tools have accurate setting information.

Please run the appropriate docs update script after any settings.yaml changes before marking the task complete.
