# INAV Configurator 9.1.0

This release is intended to be used with **INAV 9 firmware** (9.0.x or 9.1.x).

Since 9.0.1: **32 fixes** and **39 new features/enhancements**. For full PR-by-PR detail, see the [wiki release notes](https://github.com/iNavFlight/inav-configurator/wiki/INAV-Configurator-9.1-Release-Notes).

---

## Highlights

### Auto-Backup, Restore & Settings Migration

The configurator now automatically backs up your configuration before flashing firmware and offers to restore it afterwards, with automatic migration of renamed/removed settings across major versions. [#2603](https://github.com/iNavFlight/inav-configurator/pull/2603)

### GPS Tab UI Update

New GPS configuration preset system with auto-detection of module type (M8/M9/M10) and optimized presets for each. [#2526](https://github.com/iNavFlight/inav-configurator/pull/2526)

### Mission Control Updates

Drag & drop Geo file loading (KML, GeoJSON, GPX), address search, and center-on-location. [#2566](https://github.com/iNavFlight/inav-configurator/pull/2566)

### LED Tab Improvements

The LED tab is now more intuitive to use, and includes presets for different platforms. [#2543](https://github.com/iNavFlight/inav-configurator/pull/2543)

## Other Bug Fixes Since 9.0.1

- **VTOL** — Sync control profile when mixer profile changes to prevent profile mismatch. [#2644](https://github.com/iNavFlight/inav-configurator/pull/2644)
- **Mission Control** — Fix mission file saving; ensure `.mission` extension on Linux. [#2616](https://github.com/iNavFlight/inav-configurator/pull/2616)
- **OSD** — Fix custom element layout on narrow/HD and wide screens. [#2636](https://github.com/iNavFlight/inav-configurator/pull/2636)
- **CLI** — Replace fixed delay with prompt-based flow control for more reliable command sending. [#2615](https://github.com/iNavFlight/inav-configurator/pull/2615)
- **GPS** — Fix hardware version MSP read from uint32 to uint8, matching firmware fix. [#2610](https://github.com/iNavFlight/inav-configurator/pull/2610)
- **Mixer** — Remove phantom servo from output mapping display; rename smix `max` to `fixed`. [#2637](https://github.com/iNavFlight/inav-configurator/pull/2637), [#2631](https://github.com/iNavFlight/inav-configurator/pull/2631)
- **BLE / USB** — Fix Nordic BLE characteristic UUIDs and USB descriptor length mismatch. [#2590](https://github.com/iNavFlight/inav-configurator/pull/2590), [#2601](https://github.com/iNavFlight/inav-configurator/pull/2601)
