# INAV Configurator 9.1.0-RC1

> **This is a Release Candidate.** RC builds are for testing purposes. Please report any issues on [GitHub Issues](https://github.com/iNavFlight/inav-configurator/issues).

This release is intended to be used with **INAV 9 firmware** (9.0.x or 9.1.x).

---

## Highlights

### Auto-Backup, Restore & Settings Migration

The configurator now automatically backs up your configuration before flashing firmware and offers to restore it afterwards. A built-in settings migration engine updates renamed or removed settings automatically when upgrading firmware versions, with warnings when manual review is needed. [#2603](https://github.com/iNavFlight/inav-configurator/pull/2603) (@b14ckyy)

### SITL Updated to INAV 9.1.0

The bundled SITL (Software In The Loop) simulator binary has been updated to INAV 9.1.0 firmware for all platforms (Linux x64, Linux arm64, macOS, Windows).

## Bug Fixes

- **VTOL** — Sync control profile when mixer profile changes to prevent profile mismatch. [#2644](https://github.com/iNavFlight/inav-configurator/pull/2644)
- **Presets** — Remove `nav_fw_launch_climb_angle` override from airplane presets (was overwriting user settings). [#2647](https://github.com/iNavFlight/inav-configurator/pull/2647)
- **Mission Control** — Fix mission file saving; ensure `.mission` extension on Linux. [#2616](https://github.com/iNavFlight/inav-configurator/pull/2616)
- **OSD** — Fix custom element layout on narrow/HD and wide screens. [#2636](https://github.com/iNavFlight/inav-configurator/pull/2636)
- **CLI** — Replace fixed delay with prompt-based flow control for more reliable command sending. [#2615](https://github.com/iNavFlight/inav-configurator/pull/2615)
- **Advanced Tuning** — Load mixer config before rendering tab to fix display issues. [#2626](https://github.com/iNavFlight/inav-configurator/pull/2626)
- **Reboot** — Reopen the correct tab after Save and Reboot. [#2625](https://github.com/iNavFlight/inav-configurator/pull/2625)
- **GPS** — Fix hardware version MSP read from uint32 to uint8, matching firmware fix. [#2610](https://github.com/iNavFlight/inav-configurator/pull/2610)
- **Alignment Tool** — Fix sliders not linked to value fields. [#2605](https://github.com/iNavFlight/inav-configurator/pull/2605)
- **Mixer** — Remove phantom servo from output mapping display. [#2637](https://github.com/iNavFlight/inav-configurator/pull/2637)
- **Mixer** — Rename smix `max` to `fixed` to match firmware terminology. [#2631](https://github.com/iNavFlight/inav-configurator/pull/2631)
- **BLE** — Fix characteristic UUIDs for Nordic Semiconductor devices. [#2590](https://github.com/iNavFlight/inav-configurator/pull/2590)
- **USB** — Fix USB descriptor length mismatch on some chips. [#2601](https://github.com/iNavFlight/inav-configurator/pull/2601)
