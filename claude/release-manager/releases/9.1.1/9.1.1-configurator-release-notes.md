# INAV Configurator 9.1.1

Configurator-only patch release. **No firmware changes** — continues to work with INAV 9 firmware (9.0.x or 9.1.x), same as 9.1.0.

---

## Fixes

- **Flasher** — Fixed a display bug where a flash failure showed raw HTML markup (`<span style="color: red">...`) instead of a properly styled red "Failed" message. [#2678](https://github.com/iNavFlight/inav-configurator/pull/2678)
- **Outputs tab** — Corrected servo numbering and increased the display to support up to 18 servos on compatible targets. [#2680](https://github.com/iNavFlight/inav-configurator/pull/2680)
