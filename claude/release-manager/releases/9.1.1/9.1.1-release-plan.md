## ⚠️ Deviations from the standard combined-release workflow (read first)

This is **not** a standard firmware+configurator release. Per the Manager's brief:

- **No firmware tag, no firmware artifacts.** Firmware is unchanged since `9.1.0`. Do not re-download or re-verify firmware hex files.
- **Skip guide 1 steps 3-4 (SITL binary refresh).** No new firmware CI run exists to pull SITL binaries from. The SITL binaries already bundled in configurator (from 9.1.0's PR #2676, commit `f4bb28eed3`) are still current — confirmed reusable per user, 2026-07-12. No SITL rebuild, no new SITL commit.
- **Version bump PR is configurator-only:** `package.json` `9.1.0` → `9.1.1`, no SITL-binary commit riding along. Normal release-manager-owned mechanical PR (same pattern as `26234eaebb`, `113f46fa0d`).
- **No `release/9.1` branch in configurator repo** — `maintenance-9.x` remains the correct source branch here (unlike firmware, where `release/9.1` replaced `maintenance-9.x` after the wrong-direction-merge incident — see `../9.1.0/9.1.0-final-release-plan.md` branch-topology note. That incident was firmware-only; configurator's `maintenance-9.x` was never affected).
- **PG validation not applicable** — that check is firmware-only (parameter-group struct sizes); firmware hasn't moved.
- **Solo announcement.** House rule: "only hotfixes touching one repo get a solo announcement" (from the 9.1.0 plan, Phase 7). This qualifies — Configurator-only, not combined.
