## Task

Implement 4 critical bug fixes for MSP/Serial deadlock issue #11348.

## Background

Your investigation identified 4 interconnected bugs that cause FC lockup when MSP reader disconnects with LOG_DEBUG active. The issue stems from:
1. Missing return statement in serialIsConnected check
2. Lack of timeout protection in serial transmission wait
3. Blocking printf calls in logging
4. No connection status validation in log module

These bugs create a deadlock scenario where the serial module becomes unresponsive during disconnect events.
